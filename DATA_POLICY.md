# Politique de données du dépôt public

La première publication contient le code expérimental et la documentation méthodologique, mais pas les archives de données collectées, les résultats bruts de témoins ni les banques de sorties de campagnes.

Cette séparation est volontaire :

- le générateur synthétique et les hypothèses restent auditables ;
- les données réelles ou dérivées ne sont pas diffusées sans revue séparée ;
- les résultats historiques ne sont pas confondus avec une reproduction immédiate ;
- une future publication de fixtures synthétiques minimales pourra être ajoutée dans un commit distinct.
